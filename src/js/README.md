# 🚀 OrbitWatch — Live Rocket & Satellite Tracker

Track the ISS in real-time, upcoming rocket launches, and crew in space.

**Live:** https://rintuchowdory.github.io/rocket-tracker

## Features
- 🛸 Live ISS position (updates every 5 seconds)
- 🌍 Orbit trail on interactive dark map
- 🚀 Upcoming rocket launches (SpaceDevs API)
- 👨‍🚀 Current humans in space
- 📡 Speed, altitude, visibility data
- No API key needed!
